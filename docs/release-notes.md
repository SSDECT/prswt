## Download / Скачать

| System | File | How to start |
|---|---|---|
| **Windows 10/11** | [PRSWT-windows-x64.zip](https://github.com/SSDECT/prswt/releases/latest/download/PRSWT-windows-x64.zip) | Unzip and run `prswt.exe`. Nothing to install. |
| **macOS, Apple Silicon (M1–M4)** | [PRSWT-macos-apple-silicon.dmg](https://github.com/SSDECT/prswt/releases/latest/download/PRSWT-macos-apple-silicon.dmg) | Open the `.dmg` and drag **PRSWT** to Applications. |
| **macOS, Intel** | [PRSWT-macos-intel.dmg](https://github.com/SSDECT/prswt/releases/latest/download/PRSWT-macos-intel.dmg) | Same as above. |
| **Linux x64** | [PRSWT-linux-x64.tar.gz](https://github.com/SSDECT/prswt/releases/latest/download/PRSWT-linux-x64.tar.gz) | `tar xzf PRSWT-linux-x64.tar.gz && ./PRSWT-linux-x64/prswt` |

Not sure which Mac you have? Apple menu ▸ **About This Mac**: "Chip Apple M…" means Apple Silicon, "Processor Intel" means Intel.

**First start.** If a build is not code-signed yet:
- Windows SmartScreen: **More info ▸ Run anyway**.
- macOS: open PRSWT once, then **System Settings ▸ Privacy & Security ▸ Open Anyway**.

**Try it:** **File ▸ Open sample** opens a ready project. A tutorial project (an office building with risks and progress) is in [docs/examples](https://github.com/SSDECT/prswt/tree/main/docs/examples). User guide (Russian): [docs/user-guide.md](https://github.com/SSDECT/prswt/blob/main/docs/user-guide.md).

---

**Windows 10/11:** распакуйте zip и запустите `prswt.exe`. **macOS:** откройте `.dmg` и перетащите PRSWT в «Программы» (Apple Silicon — для M1–M4, Intel — для старых Mac). **Linux:** распакуйте архив и запустите `prswt`. Готовый проект для знакомства: **File ▸ Open sample**. Руководство: [docs/user-guide.md](https://github.com/SSDECT/prswt/blob/main/docs/user-guide.md).

Code signing policy: [README](https://github.com/SSDECT/prswt#code-signing-policy).
